# Cyclone Impact Analysis Using Machine Learning

A Machine Learning project that analyzes cyclone impact using environmental and atmospheric data. This project uses K-Means Clustering to group cyclones based on their characteristics and identify cyclone behavior patterns.

---

# Project Overview

Cyclones are powerful natural disasters that can cause severe damage depending on factors like:

- Wind Speed
- Atmospheric Pressure
- Rainfall
- Storm Surge
- Ocean Temperature

This project explores how Machine Learning can analyze cyclone-related data and cluster cyclones with similar impact patterns.

The main goal of this project is learning practical ML workflows using Python and Scikit-learn.

---

# Features

- Data preprocessing
- Feature scaling using StandardScaler
- K-Means clustering
- Cyclone impact analysis
- Multi-feature dataset handling
- Beginner-friendly ML workflow

---

# Dataset Features

| Feature | Description |
|---|---|
| wind_speed_kmh | Cyclone wind speed |
| pressure_hpa | Atmospheric pressure |
| rainfall_mm | Rainfall amount |
| storm_surge_m | Storm surge height |
| cyclone_size_km | Cyclone size |
| movement_speed_kmh | Cyclone movement speed |
| ocean_temperature_c | Ocean temperature |
| impact_score | Estimated cyclone impact score |
| impact_level | Cyclone severity category |
